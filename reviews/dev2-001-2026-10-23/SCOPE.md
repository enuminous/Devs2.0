# Proposed initial scope and acceptance of deliverables

**Proposed; no engagement accepted or fee agreed.**

Review one pinned package and the 12 existing development items. The original
request allowed up to six authentic conflicting-version candidates *if established*.
The attached bounded search established none; the four screened amendments are
negative eligibility examples for discussion, not a completed Tier C bank.

| Workstream | Bounded contribution | Expected deliverable |
|---|---|---|
| Question methodology | Test support/absence/conflict definitions, evidence spans, semantic absence review, neutral wording, and retrieval delivery | Worksheet for each supplied item; identify accept/revise/reject and reasons |
| Evidence-family independence | Review shared source/claim/experiment dependencies, unique-ID assumptions, family grouping and development/holdout separation | Proposed family map with justifications and unresolved dependencies |
| Statistical validity | Assess estimand, sample feasibility, paired family bootstrap, sparse outcomes, baseline headroom, decision gates, exploratory multiplicity and replication rule | Approximately 2–4 pages of evidence-linked methods findings; list necessary prospective amendments |
| Reproduction readiness | Inspect pins, setup, adapter contract, custody, accounting, raw logs, analysis and release evidence | Completed checklist with ready/blocked/not-inspected for every item |

Acceptance means all supplied items and listed methods questions receive a recorded
disposition, limitations are stated, and artifacts are tied to the baseline hash.
It does not require a favorable verdict. A negative feasibility judgment is a valid
deliverable. Any extra candidates, corpus expansion, provider integration, extensive
code changes or full execution require a separately agreed scope.

A later reproduction engagement must be separately quoted and agreed after the
complete design is frozen. It requires a new generation run by an independent
operator and different independent human raters; replaying saved responses only
checks deterministic analysis. Initial review cannot certify an unproduced result.
