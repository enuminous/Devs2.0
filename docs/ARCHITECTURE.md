# Architecture and trust boundaries

`web/template.html` + `web/style.css` + `web/engine.js` + `web/app.js` + verified repository data are compiled by `scripts/build_site.py` into one root `index.html`. The isolated `_site` output contains only the public desktop. It uses no network model calls, telemetry, CDN libraries, remote fonts, or service worker. External GitHub links are ordinary navigation. Browser notes stay in localStorage until explicitly exported; imported strings are escaped as text.

The assistant retrieves 14-line overlapping passages with lexical BM25-style scoring. Four exact starter questions use clearly labeled curated summaries whose quotations are checked at build time against the pinned paper. Other queries return extracts, not invented generated answers. Mechanical criticism checks revision/range/bytes; semantic entailment, actual contradictions, and independence remain human judgments. Browser retrieval and protocol retrieval are separately implemented and need not rank ties identically; only the Python preparation code defines experimental context.

The Python CLI has four independent stages: prepare an allowlisted gold-free context plan; generate all five configurations; create blinded human scoring packets and adjudicate disagreements; analyze the locked paired records. It never turns browser exploration into experiment data. The root `bench.py` exposes these commands unchanged. `adapters/fixture.py` is software testing only. `adapters/gateway.py` is an executable HTTPS JSON transport; a separately audited backend must provide exact input counting and pinned generation. It disables redirects and retries, and reads credentials from environment variables. The site never stores these credentials.

`Devs/` is a separate, dependency-light Lean model of selected invariants. Python and JavaScript do not import or execute proof terms. Tests and a small computed executable cross-check selected constants; they do not prove full implementation refinement. Each layer keeps its own evidence status.

Provenance starts at `IMPORT.json`, which records the reused source package and original file blob IDs. `CORPUS.json` pins corpus bytes independently of this repository's moving main branch. The experiment's package digest includes source/config/prompt files; frozen runs require a clean checkout, exact adapter digest, full roster and sealed holdout. CI artifacts and Pages deployment are software delivery records, not experimental observations.
